## Didn't work

| What happened | Root cause | Mechanism now in place |
|---|---|---|
| A unit test POSTed a fixture report to the production endpoint (07:59 UTC, 11 rows) | A refactor removed the `send(endpoint=)` hook one commit before the loopback test was rewritten; a real child process ran the production module in between | The test now redirects through `telemetry_upload._ENDPOINT` in the child; proven by D1 unchanged across all 130 telemetry unit tests. Rows deleted. **Open:** a guard that makes a unit-test child unable to reach the network at all |
| Live e2e seeded weeks the product itself prunes | The e2e rule "seed 55-59 weeks back" conflicted with the 53-week retention | Seeds 30-50 weeks back; cleanup subtracts exactly the test's own contribution, never whole weeks (`fcc8a263`) |
| A sitecustomize patch replaced `subprocess.Popen` with a function, so `asyncio` failed to import in the child | asyncio subclasses `Popen` at import | The injection subclasses `Popen` (`fcc8a263`) |
| A local `wrangler dev` tree outlived its test and held `tmp/pytest` | Only the `npx` parent was stopped | `taskkill /T` (POSIX: process group) in `finally`, and the test asserts the port is closed |
| Merging develop into PR #1166 overwrote the **released** `[0.94.0]` CHANGELOG section and left `[Unreleased]` without the new entry | A conflict resolved toward the branch side | Caught at release step 1 and restored byte-identical to `main`. **Open:** `check_release_artifacts.py` should fail when a released section differs from `main` |
| PR #1166 shipped without USAGE.md, INDEX, llms.txt and help text updates | The PR changed behaviour; the docs were updated only where the plan named them | Fixed by the release doc-review; the gate held |
| A verify script launched Playwright's bundled Chromium on the social-publisher LinkedIn profile, and Chromium's downgrade handling moved the whole profile into `automation_profile.CHROME_DELETE` | The documented recipe in `social-publisher/docs/platforms/linkedin.md` omitted `channel="chrome"` | Recovered by moves only (24 cookies before and after). The recipe now carries `channel="chrome"` and a warning |
| The owner's draft post used `gflow t2v` / `gflow i2v` | Commands written from memory | Every command in a post is checked against `--help`; recorded in memory `project-v095-promo-draft` |
| The release-promo memory pointed at a skill that no longer exists | social-publisher replaced `release-promo` with `promote` + `publishing-lane-ops` | Memory `reference-release-promo-skill` rewritten |

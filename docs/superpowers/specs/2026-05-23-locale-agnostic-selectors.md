# Design: Locale-Agnostic Selectors (Issue #24)

**Date:** 2026-05-23
**Status:** Drafting
**Topic:** Language-Agnostic Functionalities

## 1. Problem Statement
The `UiAutomationTransport` currently relies on localized text strings (e.g., "New project", "Novo projeto", "Inicial", "Final") to identify and interact with UI elements in Google Flow. This makes the tool fragile when used with Google accounts configured in languages other than English or Portuguese.

## 2. Goal
Refactor all UI selectors to be **locale-agnostic** (also called language-agnostic). We will prioritize:
1.  **ARIA Attributes:** `aria-label`, `aria-controls`, `aria-haspopup`.
2.  **Radix UI Tokens:** Stable IDs and attributes generated by the Radix UI library.
3.  **Icon Ligatures:** Material Symbols ligature names (e.g., `play_circle`, `arrow_forward`).
4.  **Structural Anchors:** Unique DOM hierarchies or non-localized data attributes.

## 3. Targeted Selectors

### 3.1 New Project CTA
- **Current:** Mix of icon and localized text ("New project", "Novo projeto", "Nuevo proyecto", etc.).
- **New:** 
    - `button:has(i.google-symbols:text('add_2'))`
    - `button:has(i:text('add_2'))`
    - `[aria-label*='Project' i]`
    - `button:text-matches('\+\s+\S+', 'i')` (Matches "+ " followed by any non-whitespace)

### 3.2 Onboarding & Bypass
- **Current:** "Agree", "Aceitar", "Concordo", "Get Started", "Começar".
- **New:** Use structural positioning or unique parent containers. For cookie banners, look for common patterns like `role='dialog'` with a primary button.

### 3.3 Mode Switching (Image/Video)
- **Current:** `has-text('Imagem')`, `has-text('Video')`.
- **New:**
    - `[role='tab'][aria-controls*='IMAGE']`
    - `[role='tab'][aria-controls*='VIDEO']`
    - `i:text('image')`
    - `i:text('play_circle')`

### 3.4 Video Sub-modes (Frames/Elementos)
- **Current:** `has-text('Frames')`, `has-text('Quadros')`, `has-text('Elementos')`.
- **New:**
    - `[role='tab'][aria-controls*='VIDEO_FRAMES']`
    - `[role='tab'][aria-controls*='VIDEO_REFERENCES']`

### 3.5 Image Slots (Inicial/Final)
- **Current:** `has-text('Inicial')`, `has-text('Final')`.
- **New:** Use positional selectors within the Frames container or `aria-haspopup='dialog'` on specific children.

### 3.6 Aspect Ratio Tabs
- **Current:** `1:1`, `Square`, `1×1`.
- **New:** Match the numeric pattern or use `aria-controls` tokens (e.g., `9_16`, `16_9`).

## 6. Definition of Done
- All `has-text()` selectors using human-readable strings are removed or relegated to last-resort fallbacks.
- The tool successfully navigates and generates content on a non-English account (verified e2e).
- `pyright` and `ruff` pass.
- Scoped test suite passes.

## 7. Backlog (Future Work)
### 7.1 MCP Server Implementation (Strategic Agnosticism)
- **Goal:** Expose all `gflow-cli` capabilities (image generation, video generation, project management) via the Model Context Protocol (MCP).
- **Benefit:** Allows any AI agent (regardless of its implementation language) to drive `gflow-cli` using standard tool definitions.
- **Entry point:** `gflow mcp start`.
- **Status:** Deferred; priority is selector stability.

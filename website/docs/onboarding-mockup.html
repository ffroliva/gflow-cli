Get started with gflow-cli

One package, two doors onto Google Flow: the gflow CLI in your terminal and an MCP server for your AI assistant. Install once, sign in once, then use either.

Before you begin
gflow-cli is beta, reverse-engineered and not affiliated with Google. It drives a real Chrome session signed in to your own Google account, which needs Flow access. Video spends your Flow credits; images spend none, but count against a daily image quota.

Prerequisites

✓ Python 3.11+ (uv installs a managed Python) ✓ Google account with Flow access ✓ Google Chrome installed ✓ Display for one-time browser login ✓ Optional: an MCP client (Claude Code, Claude Desktop, Cursor, VS Code, Codex)
Install

One command puts gflow on your PATH. Then install the browser engine it needs (~150 MB).

Install the CLI:

Terminal
$ uv tool install gflow-cli

Install Chromium (one-time, required by the browser transport):

Terminal
$ uv tool run --from gflow-cli playwright install chromium

Verify the installation:

Terminal
$ gflow --version
Output
gflow, version 0.106.0
Next: Authenticate
Authenticate

A one-time login opens a real Chrome window. Sign in with your Google account and keep going until the Flow editor loads — gflow closes the window for you and verifies the session automatically.

Use --browser chrome — the default auto picks the same real Chrome when it is installed, and only this strategy marks the profile as a real-Chrome profile.

Terminal
$ gflow auth login --browser chrome
What happens
A Chrome window opens at the Flow sign-in page.
Sign in with your Google account (2FA included).
Keep going until the Flow editor loads.
gflow CLOSES THE WINDOW for you and verifies automatically.
Session saved.
Profile dir: ~/.local/share/gflow-cli/profile_default
Renamed profile from default to your-name (derived from Google account).

On first run, the profile is created as default then auto-renamed to your email's local-part (e.g. your.name@gmail.com → your-name). Single-account users never have to think about profiles. To use a custom name, pass --profile myname.

Next: Connect your assistant
Connect your assistant

Register the MCP server with your client. It runs the same code as the CLI, on the same signed-in profile, so an assistant can generate, upscale and manage media for you.

Claude Code: install the plugin from inside Claude Code. It adds the MCP server and two skills, and ships disabled until you enable it.

Claude Code
> /plugin marketplace add ffroliva/gflow-cli
> /plugin install gflow@gflow-cli

Claude Desktop, Cursor or VS Code: one command writes the server entry into the client's config.

Terminal
$ gflow mcp setup
$ gflow mcp setup --target cursor
$ gflow mcp setup --target vscode
What happens
The gflow entry is merged into the client's config file.
Existing content is kept; the old file is backed up as <name>.gflow-backup.
An entry that is already there is left untouched.
Restart the client to load the server.

Any other MCP client: command uvx, arguments gflow-cli mcp run, or gflow serve for Streamable HTTP at /mcp. To keep an assistant away from your credits, register gflow mcp run --no-spend: the tools that spend credits are never registered. Full setup: MCP server.

Next: Generate
Generate

From the terminal, one command gives you a real file. From your assistant, ask in plain language and it picks the tool, model and aspect.

Make an image. --tool creative-director expands your prompt before anything is sent to Flow.

Terminal
$ gflow image t2i "a lighthouse in a storm, moody, cinematic" --tool creative-director
Output
Flow project created: project/abc123
Generating images…
✓ out/images/2026-11-23/8f3a1b2c_1.png

Make a short video. --max-credits caps what the run may spend: if Flow quotes more, gflow stops before submitting (exit 45).

Terminal
$ gflow video t2v "a paper boat drifting across a calm pond at dawn" --max-credits 10
Output
Generating video… (about a minute)
✓ out/videos/2026-11-23/9e4d7f2a.mp4

Or ask your assistant:

Prompt
Make a 16:9 image of a lighthouse in a storm, then turn it into a short video. Spend at most 10 credits.

Files land in ./out/images/ and ./out/videos/ by default. Route outputs to S3, MinIO, or GCS with external storage.

Troubleshooting

If something goes wrong on this path, here are the most common errors and exactly how to fix them.

AuthBrowserRejectedError (exit 14)
Google's sign-in rejected the login browser for advertising automation (navigator.webdriver).
Fix: Install Google Chrome from chrome.com, then restart your terminal and run:
gflow auth login --browser chrome
No profiles found (exit 2)
You ran a generation command before signing in, so no profile exists yet.
Fix: Run the one-time login first:
gflow auth login --browser chrome
Authentication credential missing (exit 8)
The profile exists but has no usable Flow session: the account is signed in to Google but not to Flow, or the login did not finish.
Fix: Sign in again with the real-Chrome strategy:
gflow auth login --browser chrome
Authentication expired (exit 3)
Your browser session is no longer valid.
Fix: Re-authenticate:
gflow auth login --browser chrome
Profile locked (exit 11)
Another process holds this profile directory.
Fix: Close any running gflow serve daemon or stray Chrome windows, then retry.
